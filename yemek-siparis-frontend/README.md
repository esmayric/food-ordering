# Gurmia Frontend

React 18 tabanlı Gurmia kullanıcı ve admin arayüzü.

## Çalıştırma

```bash
npm install
npm start
```

Varsayılan backend adresi `http://localhost:5000`'dir. Farklı adres için `.env.example` dosyasını `.env` olarak kopyalayıp `REACT_APP_API_URL` değerini değiştir.

Ana proje kurulumu ve veritabanı migration bilgileri için bir üst klasördeki `README.md` dosyasına bak.
